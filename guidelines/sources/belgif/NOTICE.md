# Belgif REST API guide (copy)

These files are the chapters of the **Belgif REST API guide** ("REST guidelines"), copied unchanged from https://github.com/belgif/rest-guide, commit `0ccd7d8` (2026-11-12), folder `src/antora/modules/ROOT/pages`. The rendered guide is at https://www.belgif.be/specification/rest/api-guide/.

The spec factory uses them only as input for its rules (ids `BLG-...`, built by `guidelines/build_rules.py`); the rule ids keep the guide's own ids (`rule-err-problem` becomes `BLG-err-problem`). The problem type annexes are not copied.
